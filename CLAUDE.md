# REGLAS OBLIGATORIAS DE FRONTEND — ARGENTUM

Nota: `.agents/`, `.claude/` y `.codex/` no se versionan en Git. Este archivo es la fuente canónica.

1. **Constitución Visual:** Leer `DISENO_UNIFICADO.md` antes de tocar cualquier CSS o TSX de interfaz.
2. **Tokens Estrictos:** Usar únicamente variables de `tokens.css` y `elevation.css`. Prohibido introducir sombras, z-index, radios o espaciados literales sueltos.
3. **Selectores Canónicos:** Todo selector segmentado debe usar `ui/SegmentedControl` (componente oficial Opción 4: sin pista ni card contenedora detrás, botones sueltos con gap 6px (`var(--selector-gap)`); botón inactivo transparente, sin borde, texto gris (`var(--text-2)`), 13px, peso 600; botón elegido con fondo `var(--primary)`, texto `#FFFFFF`, peso 700 y sombra suave `var(--elevation-pill)` con alcance 8px, igual que el punto activo del indicador de pasos; alto 40px, 44px en táctil y 56px apilado; admite la prop opcional `description?: string` para una segunda línea secundaria de 11px y peso 500 bajo el label en modo apilado para valores o cotizaciones sin cortes; admite la prop opcional `badge?: number | string` para contadores junto a la etiqueta; admite layout `'wrap'` para listas de 4 o más opciones en varias filas; si se omiten, mantiene su estructura de una sola línea). La Opción 1 de la página admin Diseño es una copia independiente y su botón elegido es blanco; el componente oficial (Opción 4) usa el color primario por decisión de Sebastián del 17/10. No crear `.segmentedBar`, `.methodGrid`, etc.
4. **Anatomía de Modales:** Respetar la estructura oficial de `DISENO_UNIFICADO.md` (lateral 20px, radio 20px, prop `stepDots` para pasos > 1 arriba de todo, prop `footer={<ModalFooter secondary={...} primary={...} />}` con Cancelar flex 1 y Confirmar flex 2 sin borde divisor). El overlay del Modal base sigue en su capa actual hasta la tanda de remapeo de portales. Pendiente: altura adaptativa (hook `useAdaptiveModalHeight` v2) en la tanda siguiente.
5. **Prohibiciones Clave:** Prohibido agregar `!important` y márgenes negativos (`margin: -...`). Prohibido rebote en animaciones (`cubic-bezier > 1`).
6. **Verificación Previa:** Correr `npm run lint` (incluye `audit:rules`) y `npm run build` antes de subir cambios. La línea base no puede subir.
7. **Dudas o Casos no Cubiertos:** Preguntar directamente a Sebastián antes de inventar nuevos estilos o excepciones.
8. Antes de cada push corre solo un control (se instala con npm install o npm run dev). Si corta el push, corregí lo que marca. No uses --no-verify.
